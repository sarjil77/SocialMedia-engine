# Background Music

Place royalty-free trending background music loops here.

## Specs
- **Format:** MP3 or AAC
- **Duration:** 15–60 seconds (will be looped/trimmed automatically)
- **Style:** Upbeat, food-content friendly, no lyrics preferred

## Naming
- `upbeat_trendy.mp3`
- `chill_lofi.mp3`
- `festive_dhol.mp3`

The video editor picks the first available track or you can map tracks to categories in config.
