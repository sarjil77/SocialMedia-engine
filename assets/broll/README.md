# B-Roll Clips

Place 1.5–3 second 9:16 vertical video clips here for prepending as hooks to Reels.

## Naming convention
Filenames should match the `recommended_broll_tag` values from the AI analyzer:
- `chocolate_pour.mp4`
- `oven_glow.mp4`
- `cream_swirl.mp4`
- `sprinkle_rain.mp4`
- `dough_knead.mp4`

## Specs
- **Resolution:** 1080×1920 (9:16 vertical)
- **FPS:** 30
- **Duration:** 1.5–3 seconds
- **Codec:** H.264 / AAC (or silent)
