# Fonts

Download and place the following Google Fonts here:

## Required fonts
1. **Montserrat Bold** — Primary hook text overlay
   - Download: https://fonts.google.com/specimen/Montserrat
   - File needed: `Montserrat-Bold.ttf`, `Montserrat-ExtraBold.ttf`

2. **Noto Sans Gujarati** — Gujarati script support
   - Download: https://fonts.google.com/noto/specimen/Noto+Sans+Gujarati
   - File needed: `NotoSansGujarati-Bold.ttf`

3. **Poppins** (optional fallback)
   - Download: https://fonts.google.com/specimen/Poppins
   - File needed: `Poppins-Bold.ttf`

## Quick download (via terminal)
```bash
# Montserrat
curl -Lo Montserrat-Bold.ttf "https://github.com/google/fonts/raw/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf"

# Noto Sans Gujarati
curl -Lo NotoSansGujarati-Bold.ttf "https://github.com/google/fonts/raw/main/ofl/notosansgujarati/NotoSansGujarati%5Bwdth%2Cwght%5D.ttf"
```
