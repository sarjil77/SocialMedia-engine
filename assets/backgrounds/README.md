# Backgrounds

Place luxury product-photography backgrounds here (1080×1920 or 1080×1080 JPEG/PNG).

## Recommended style
- **Marble slab** (white / dark Emperador)
- **Rustic wood plank** (warm oak)
- **Matte black / slate** surface
- **Gradient pastel** (soft pink, cream)

Each file should be named descriptively:
- `marble_white.jpg`
- `dark_wood.jpg`
- `slate_black.jpg`
- `pastel_pink.jpg`

The image editor randomly picks one (or matches by category) when compositing product shots.
